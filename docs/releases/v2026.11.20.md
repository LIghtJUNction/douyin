# douyin-cli v2026.11.20

- 新增 `publish video`，通过官方 OAuth 投稿。大视频支持有界分片上传，投稿记录保留提交意图，支持查询和恢复，降低网络中断后重复投稿的风险。
- 新增 `publish app` 原生创作者投稿入口，以及原生扫码登录引导、私密会话持久化和终态记录。
- OAuth 区分申请权限与服务端确认权限，状态查询核对实际账号。投稿记录明确标注尚未查询的审核状态。
- 下载可恢复已有空文件，并在有限次数内尝试其他 CDN 地址。

原生扫码实测已取到二维码，随后轮询收到服务端错误码 `4031`。完整扫码登录、真实上传、投稿和审核回查仍待验收。官方大视频分片上传也仍待具备对应权限的真实账号验收。

- [原生创作者投稿与验收记录](https://github.com/LIghtJUNction/douyin/blob/v2026.11.20/docs/native-publishing.md)
