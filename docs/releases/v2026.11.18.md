# douyin-cli v2026.11.18

本版补齐官方视频投稿的分片上传、权限预检和失败恢复。超过 50 MiB 自动使用官方分片接口；创建请求结果未知时保留已上传的视频信息，要求先核实账号中的作品，再显式决定是否重试。

## 主要变化

- 上传文件和分片均使用限长文件流；默认每片 20 MiB，短于 5 MiB 的尾部并入前一片。
- 上传独立超时默认 300 秒，可用 `--upload-timeout` 调整；普通 OpenAPI 请求保持 30 秒。
- 新增 `publish video --dry-run`、`--upload-only`、`--receipt`，以及 `publish status` 和 `publish resume`。
- 投稿记录绑定 OAuth 应用和账号，不保存 token 或 client secret。文件原子替换、进程互斥锁及 Unix 目录同步保护恢复状态。
- 创建阶段在请求前保存，`creating`、`unknown` 不自动重试；已有 `submitted` 记录只读取结果。
- OAuth 分开保存请求权限与服务器授予权限，修复未完成重新授权时误报新权限及换账号继承旧 token 元数据的问题。
- 上传前校验 `video.create.bind`、已知 token 到期时间、文件、1000 字标题及有限非负封面时间。
- 下载器支持空文件原子恢复和最多 8 个 CDN 候选依次回退，拒绝目录、截断内容和未请求的部分响应。
- OAuth 在线检查要求返回账号 ID 与本地一致；投稿本地状态以 `review_status: "not_queried"` 明确表示审核结果未查询。
- 投稿记录在操作结束时主动解锁，避免复制或临时继承的文件描述符延迟释放锁。

## 使用

```bash
douyin auth login --scope user_info,video.create.bind
douyin publish video ./video.mp4 --title "标题 #话题" --dry-run
douyin publish video ./video.mp4 --title "标题 #话题" --yes
```

分步投稿及恢复：

```bash
douyin publish video ./video.mp4 --upload-only --receipt ./video-receipt.json --yes
douyin publish status ./video-receipt.json
douyin publish resume ./video-receipt.json --yes
```

作品创建后进入平台审核。详细参数、阶段含义、验证范围和官方文档链接见 [视频投稿指南](../publishing.md)。
