# douyin-cli v2026.11.17

本版扩展抖音主播直播的命令行操作，并支持从 Android 41.1.0 导入原生登录态。直播生命周期已通过自动化测试；真实创建房间、推流、续播和结束尚未完成端到端验收。

## 主要变化

- 新增直播续播、主播状态上报、有限次心跳和结束状态回读。
- 创建或续播后可保存账号绑定的私密会话，直接供 OBS 配置推流。文件拒绝覆盖；Unix 权限为 `0600`。
- 手机通道新增固定直播 GET/POST 路由，按已核对的 40.8.0、41.1.0 构建选择网络入口。
- Android 登录改为按 Keva 活跃键读取当前安装 ID，解决旧 XML 值导致的 41.1.0 导入失败。
- 预检错误会显示服务端提供的简短说明，同时保留错误码。
- 修复 Windows CI 的 SQLite 安装路径，并新增按版本标签构建 Linux、macOS、Windows 下载包的发布流程。

## 验证与已知范围

- Rust 测试 **180 项通过、1 项按项目原配置跳过**；严格 Clippy 和手机桥接夹具通过。
- Android 41.1.0 真机原生 Token 导入与在线账号核对成功，`live permissions`、`live create-info` 的电脑直连查询成功。
- 同一设备的 `live create-check` 返回服务端错误码 `10001`；手机通道仍在 Frida 附加阶段失败。本轮没有实际开播或推流。

使用步骤、参数含义和错误恢复见 [直播指南](https://github.com/LIghtJUNction/douyin/blob/v2026.11.17/docs/live.md)，协议依据见 [安卓直播协议记录](https://github.com/LIghtJUNction/douyin/blob/v2026.11.17/docs/android-live-protocol.md)。

## 安装

```bash
cargo install douyin-cli --version 2026.11.17 --locked
douyin --version
```

预编译压缩包按平台提供，附带项目许可与必要的第三方许可文本；Windows 包包含 SQLite 运行时 DLL。
